# Ingest a source

1. Read `AGENTS.md`, `Schema/page-types.md` and `Schema/naming-conventions.md` if you have not this session.
2. Follow the **Ingest** steps in `Schema/workflows.md`.
3. Do not edit the file in `Raw/`.
4. Finish by telling the person which pages you created and which you updated.
