# Query the wiki

1. Start with `Wiki/index.md` and `search-catalog`, not with `Raw/`.
2. Follow **Answer a question** in `Schema/workflow-examples.md`.
3. Answer only from the wiki and its sources. If you add anything from your own knowledge, say so clearly.
4. If the wiki cannot answer, say so and suggest what source would help.
