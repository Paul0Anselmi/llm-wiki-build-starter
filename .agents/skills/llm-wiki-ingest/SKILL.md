# Ingest sources into the wiki

1. Read `AGENTS.md`, `Schema/frontmatter-schema.md` and `Schema/naming-conventions.md` if you have not this session.
2. Follow **Ingest a new source** in `Schema/workflow-examples.md`.
3. Write only under `Wiki/`. Do not change a source's content; only set `Processed: true` once it is covered.
4. Every note you create or update lists the source in `sources` with the right `source_count`.
5. Finish by running the maintenance gate and telling the person which notes you created and updated.
