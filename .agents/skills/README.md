# Agent skills

Skills that live inside this vault and teach the agent how to do recurring jobs here. Each skill is a folder with a `SKILL.md` file.

- `ingest-source/`: turn a new file in `Raw/` into wiki pages.
- `query-wiki/`: answer a question using the wiki.
- `lint-wiki/`: check the wiki against `Schema/lint-checklist.md`.

The full rules are in `AGENTS.md` and `Schema/`. The skills point there rather than repeat them.
