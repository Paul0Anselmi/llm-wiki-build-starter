# Lint the wiki

1. Run `lint` and `source-lint` from `scripts/wiki_tool.py` when they exist.
2. Go through `Schema/lint-checklist.md` for anything the scripts do not cover.
3. Fix only small, safe problems yourself. Ask before deleting, merging or renaming notes.
4. Report what you fixed and list what needs a decision.
