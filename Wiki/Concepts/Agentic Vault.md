# Agentic Vault

## Summary

An agentic vault is a vault that AI agents write and work from, kept apart from the human vault where a person's own thinking lives.

## Details

- **The problem it solves**: people switch between AI tools because of rate limits and performance. Each tool has its own memory, which works inside that tool and fails when switching. The source says the knowledge is not lost, only trapped in each tool's silo.
- **The answer**: put the context in a structure of its own, an [[LLM Wiki]], that every tool can read.
- **Together or apart**: the shared wiki can be part of a person's existing knowledge base or completely separate. The source's author, [[Wanderloots]], keeps two vaults: a human vault with only his own thinking, and an LLM vault for AI-generated notes. That way it is always clear what came from him and what came from AI.
- The source calls the pair the closest thing to a true second brain: an augmented personal knowledge management system.
