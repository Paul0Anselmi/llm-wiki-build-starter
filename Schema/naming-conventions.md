# Naming conventions

Consistent names keep links working and make pages easy to find.

## Files

- Wiki page files use the page title with normal capitals and spaces: `Wiki/Machine Learning.md`.
- Source pages start with `Source - `: `Wiki/Source - Attention Is All You Need.md`.
- Raw files keep the name they arrived with. If you rename one, use lowercase words joined by hyphens, with the date first when it matters: `Raw/2026-01-31-meeting-notes.md`.
- No characters that break links: `# ^ [ ] | \ / : ? * " < >`.

## Titles

- One idea per page, named by the plainest common name: `Large Language Model`, not `LLMs and their uses`.
- Singular, not plural: `Vector Database`, not `Vector Databases`.
- People by full name: `Ada Lovelace`.
- Spell out an abbreviation in the title and add the short form as an alias in frontmatter: `aliases: [LLM]`.

## Links

- Link with wikilinks: `[[Large Language Model]]`.
- To show different text: `[[Large Language Model|LLMs]]`.
- Link the first mention of a page on another page, not every mention.

## Tags

- Lowercase, hyphenated, few: `#to-review`, `#contradiction`.
- Use tags for status, and pages and links for subjects.
