# Schema

The rules the agent follows when it writes the wiki. Start with `AGENTS.md` at the top of the vault, then read these:

- `page-types.md`: the kinds of wiki pages and what each one contains.
- `naming-conventions.md`: how files, titles and tags are named.
- `workflows.md`: step by step guides for ingest, query and lint.
- `lint-checklist.md`: what a healthy wiki looks like, checked during lint.

You own these files. The agent may suggest changes, but asks before making them.
